Install flywheel
Flywheel comes in three flavors. Pick one, compare them below, then follow the steps.

      


      

        
        
        
      


      

        

          
flywheelflywheel liteflywheel.js

          
            
What it isCompiler on LLVM that produces native executablesBytecode virtual machine in portable C11; one ~0.5 MB executableTree-walking interpreter in one dependency-free JavaScript file

            
Best forReal projects, shipping programs, anything performance-sensitiveScripts and tools, quick setups, machines without LLVMLearning, demos, prototyping, embedding Flywheel in a web page

            
SpeedFaster — runs .fw directly (faster than Python) or compiles to native codeMiddle — about CPython speed; starts in ~1 msSlower — an interpreter; long runs are stopped in the playground

            
Runs in browserNoNoYes — browser, Web Worker or Node

            
InstallInstaller script builds it (LLVM 21–23 + CMake)Quick — installer script; needs only a C compiler, builds in secondsNone in the browser; a script tag, one file, or npx

            
Compile to an executableYes — flywheel build -O3NoNo

            
Type checkingYesAt run time — mismatches raise TypeError when reachedNo — programs the compiler rejects may still run

            
Files, network, processes, databasesYes — fs, net, os, sqlite, HTTPS, threadsPartly — fs, os processes, json, time, html; no net, sqlite or threadsNo — a browser-safe subset (json.load and flywheel.run work in Node)

            
Native code importsYes — C, C++, Rust, ZigNoNo — raises a catchable NativeError

            
PlatformsLinux, Windows, macOSLinux, Windows, macOSAnywhere JavaScript runs
